# ADR-153 — AI alt text is withdrawn from the admin

- **Status:** Accepted
- **Date:** 2026-09-22
- **Module:** 18 (AI platform), 11 (media library)
- **Plan:** owner request, 2026-09-22: "remove alt text ai suggestion in
  image... no need to generate that from ai"
- **Amends:** ADR-097's Phase 2 feature list and changes-29 B5 (alt text)
- **Does not change:** any other AI feature, the `AI_FEATURES` registry
  shape, the one-door rule (`runAiTask`/`streamAiTask`), or how alt text is
  stored and used (`MediaAsset.altText`, copied into an inserted image)

## Context

changes-29 B5 shipped two ways to have a model write alt text: a "Describe
it" button beside the Alt text field in the media detail dialog, and a bulk
"Describe images with no alt text" panel under the Media library. The owner
does not want alt text generated by AI. A person writes it.

## Decision

1. **Both entry points are removed**, along with their server actions
   (`suggestAltTextAction`, `suggestAltTextBulkAction`), the
   `alt-text-review.tsx` component, their label builders and their
   `admin.ai.altText*` catalog strings.
2. **The `alt_text` switch is hidden in Settings → AI → Features.** With no
   screen calling it, a switch would save and change nothing, which is what
   code-style.md #28 forbids.
3. **The plumbing below the UI is retained, not deleted**, in the ADR-042
   sense: the `alt_text` registry key, its prompt builder, `@repo/core`'s
   `ai-media.ts` service, the run route's permission map entry and its
   seeded `AiFeatureConfig` row. Deleting them touches the seed, the
   database and the AI package's tests, and needs its own change. Past
   usage rows that name `alt_text` stay readable on the Usage tab.

## Consequences

- An admin sees no AI control anywhere near alt text.
- `apps/web/app/ai-degradation.test.ts` now guards the ABSENCE: it fails if
  the review component returns, if a media screen or the AI actions name
  `suggestAltText`, or if the Features tab stops filtering `alt_text`.
- Bringing it back is a new ADR superseding this one.
